# Playground

Low-friction **visual** use of catalogued capabilities. Begin with source → transform → output and live parameter controls, then consider connectors or block coding only if real experiments justify it.

The first experimental GUI currently lives in `../Studio/`; migrate only after its behavior and user interactions are proven. A graph/recipe must be serializable and safely validated before applying it. LLM context should include only relevant capability contracts, examples and current experiment state.

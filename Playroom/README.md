# Playroom

The capability discovery, experimentation and research environment for Manifold Console.

- [Axioms](Axioms/): stable and candidate *contracts* for small composable capabilities implemented in Lib or AppOS
- [Playground](Playground/): low-code/no-code visual composition and parameter experiments
- [Research Campus](Research_Campus/): unconstrained prototypes, failed experiments and novel synthesis
- [Studio](Studio/): first runnable signal Playground prototype
- [Kinect](Kinect/), [UI](UI/), [AR](AR/), [VR](VR/): existing domain experiments

Applications are finished, demonstrable experiences. Lib holds reusable algorithms; AppOS handles UI/navigation and runtime policy. Research → Library/Application is a selective promotion, not a mandated linear workflow.

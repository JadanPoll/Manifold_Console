# Axioms — internal codename for Capabilities

Public console label: **Capabilities**. Internal project name: **Axioms**, inspired by the idea of an expanding repertoire of high-level reusable demonstrations and interactive abilities. The low-level algorithms and implementation mechanisms belong in `Lib/`; AppOS supplies shared services; the capability catalog belongs here.

Axioms is not another mandatory abstraction or API layer. An entry can reference a direct hardware API, library algorithm, or composite demo. Discoverability and accurate limitations matter more than forcing every implementation into one model.
